Q1 A data structure is a specialized format for organizing, processing, retrieving and storing data in computer memory so it can be used efficiently. These are broadly split into linear and non-linear.

1 Linear Data Structure: Elements are arranged in a sequential, linear order where each element is connected to its previous and next neighbor. • Array: A fixed-size collection of elements of the same data type stored at contiguous memory locations. • Linked List: A sequence of nodes where each node contain data and a reference to the next node, allowing flexible memory allocation. • Stack: A collection that follows last in first out i only one door for input & output. • Queue: A collection that follows first-in-first-out, image it as a pipe.

Non-Linear Data Structure: Elements are arranged severally; instead they connect in hierarchical or network relationship. • Tree: A hierarchical structure consisting of a root node with branching child node, commonly used for file system. • Graph: A network of nodes (vertices) connected by links (edges), used to represent web link social media connections or map.<|im_

An algorithm is a step by step procedure or set of rules designed to perform a specific task or solve a defined problem.

Characteristics of Good Algorithm: A high-quality algorithm must meet several key technical and practical standards.

Inputs: It must have zero or more well-defined inputs.

Outputs: It must produce at least one clearly defined output matching the goal.

Definiteness: Each step must be completely unambiguous and clearly stated.

Effectiveness: Every instruction must be basic enough to be carried out exactly.

Language Independence: The underlying logic must apply to any programming language.

Finiteness: It must terminate after a specific limited number of steps.

Feasibility: It must work effectively within available system resources like time and memory.<|im_

Complexity analysis is a technique used to measure the efficiency of an algorithm in terms of computer resources it consumes as input size grows.

Types of complexity Analysis:

Time complexity:-

Measure the total execution time required by an algorithm to run to completion as a function of the input size.

Space complexity:-

Measures the total amount of working memory or storage space required by the algorithm during its lifecycle.

Cases Used in Complexity Analysis:

Worst case:-

The maximum possible resources required for any input of a given size, typically denoted using Big O notation.

Best case:-

The minimum possible resources required for most ideal input scenarios, typically denoted using Big omega (Ω).

Average case:-

The expected amount of resources required taken over all possible inputs, typically denoted using Big theta (Θ).<|im_

An array is a linear data structure that stores elements of the same data types in contiguous memory location allowing direct access to any element using an index.

A linked list is a linear data structure where elements are not stored in contiguous memory location but are instead linked memory locations together sequentially using pointers or references within each node.

Key Differences:

- Memory Allocation: Arrays use fixed, contiguous memory; linked lists use dynamic scattered memory.
- Access speed: Arrays allow instant access via index. Linked require traversing from the start node.
- Insertion / Deletion: Arrays require shifting elements; linked list required updating only a few pointers.<|im_
